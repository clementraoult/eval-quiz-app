# Le registre est privé : sans authentification, le téléchargement est refusé.
$ docker logout clemanas.azurecr.io
Removing login credentials for clemanas.azurecr.io
$ docker pull clemanas.azurecr.io/quiz-backend:a47334d
Error response from daemon: error from registry: authentication required, visit https://aka.ms/acr/authorization for more information.

# Avec authentification Azure (jeton temporaire), le téléchargement fonctionne.
$ az acr login --name clemanas
Login Succeeded
$ docker pull clemanas.azurecr.io/quiz-backend:a47334d
Status: Downloaded newer image for clemanas.azurecr.io/quiz-backend:a47334d
clemanas.azurecr.io/quiz-backend:a47334d
